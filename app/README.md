# FastAPI Toxicity Prediction

* main.py 
* test_data - тут тестовые json

Реализовано:
 - POST /forward: принимает на вход json c формулой и физикохимическими свойсвами, возвращает фурмулу и признак токсичности в формате json. Если запрос неверного формата, то должен возвращаться код ошибки 400 с текстом ‘bad request’
Если модель не смогла выполнить работу, то необходимо вернуть код ошибки 403 и вернуть сообщение: “модель не смогла обработать данные”
 - GET /history для просмотра история всех запросов. 
 - GET  /stats, который возвращает статистику запросов. 
 - DELETE /history, который удаляет историю предыдущих вызовов.
